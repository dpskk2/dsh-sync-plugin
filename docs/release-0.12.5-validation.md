## GitHub About 建议

DeepSeek Harness 多电脑同步：通过自己的 GitHub 私有仓库同步会话、附件、设置与工作区文件，支持自动合并、备份状态查看及失败重试。

## 真实双机演示验收顺序

1. 两台 DSH Web 设备连接同一个已确认私有的 GitHub 仓库。
2. A 新建会话和工作区文件并同步，B 使用不同工作区根路径恢复。
3. 双方分别修改文件后同步，核对合并内容及备份分支。
4. 断开 B 网络后修改并同步，确认界面显示失败，CLI 退出码非零。
5. 恢复网络重试，确认 A 收到修改，并从备份分支读回冲突前版本。
6. 记录宿主、Node.js、操作系统版本及实际结果后再标记为真实双机通过。
